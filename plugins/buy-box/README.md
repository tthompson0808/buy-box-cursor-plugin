# Buy-Box for Cursor

Connects Cursor to the hosted Buy-Box MCP server at `https://buybox.agentconsult.ai/mcp`.

Buy-Box stores your buying criteria by category (cars, homes, rental properties, anything) so the agent reads your rules before it searches, then scores listings you paste against them. It does not search the web, buy anything, or contact sellers.

- Sign in with Google the first time Cursor connects. Each account sees only its own buy boxes.
- Try: "What buy boxes do I have saved?" or "Save a cars buy box: max $25,000, under 60,000 miles."
- Privacy: https://buybox.agentconsult.ai/privacy . Support: https://buybox.agentconsult.ai/support

This repository holds only the plugin manifest and server URL. The server is a hosted service.
